# 30-day modular learning plan

Teach a short lesson whenever requested; track progress only within available conversation context.

Week 1: pronouns, greetings, questions, `bai/bin/pinis`, time, negation, numbers, days.
Week 2: daily life: family, travel, lodging, shopping, directions, transport, social chat.
Week 3: workplace: shift handover, equipment, safety, training, attendance, photos, notices.
Week 4: advanced: politeness, requests, negotiation, ambiguity in real messages, role-play, translation corrections.

Each lesson format:
1. One grammar or communication goal.
2. Three high-frequency examples (Tok Pisin + Chinese + optional English).
3. Pronunciation notes only where confidence is high; avoid fabricated IPA.
4. Two user exercises and feedback.

Start with practical phrases; explain grammar accurately and avoid claiming Tok Pisin has no grammar.
