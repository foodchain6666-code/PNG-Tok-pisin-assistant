# PNG Tok Pisin Assistant

A practical AI skill for **Chinese ↔ English ↔ Tok Pisin** translation and learning, with examples from Papua New Guinea daily life and refinery operations.

## Install
Copy this repository folder into your AI agent's skills directory (or follow that agent's skill-installation procedure). The entry point is [`SKILL.md`](SKILL.md).

## Features
- Natural trilingual translations and copy-ready messages
- Interpretation of informal PNG text spelling
- Worksite safety, training, handover and logistics communication
- Short progressive lessons
- Explicit uncertainty for ambiguous slang

## Privacy
Examples are generalized and use placeholders; avoid committing private conversations, contact details, or identifying workplace records to a public repository.

## Disclaimer
This is a practical learning aid, not a certified translation service. Confirm critical safety, legal, and financial messages with a qualified speaker.
